# Postman Collection

This directory will contain the Postman collection for API testing.

## Steps to use:
1. Import the collection JSON file into Postman
2. Set up environment variables (base_url, token)
3. Run the collection

Collection will include:
- Auth (Register, Login, Refresh, Logout)
- Leads (CRUD + Assign)
- Deals (CRUD + Stage Update)
- Followups (Create, List, Complete)
- Activities (Create, Timeline)
- Dashboard (Stats)
- Audit Logs (List)
